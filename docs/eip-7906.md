# EIP-7906: transaction assertions

This branch restores assertions on top of the canonical EIP-8272 envelope in
`upstream/hegota-testnet` at `536d7953ac61a67c72bc04935843c694ae1a7bd6`.
Its compatibility target is Reth's `frames-eips` checkout at `ce5d5648f3`, with
revm `035f51522b90080440c9ed60337c80823c0b3f43`. These are experimental EIP
implementations; compatibility with future draft revisions is not implied.

## Execution

`POST_TX` is frame mode 3. It must form a contiguous suffix and cannot carry the
atomic-batch flag. Modes 4 and above remain reserved. Assertions execute with
`ENTRY_POINT` as caller in a static call subtree. `APPROVE` is forbidden there.

A failed assertion ends the suffix and produces an included transaction with
status 0. It restores the execution body's state, logs, state-gas attribution,
and refundable state charges. The validation prefix through the first successful
payment approval remains committed. Execution gas, payer charging, and nonce
consumption remain in effect. The prefix boundary is determined at execution,
including for block-valid prefixes outside the public mempool templates.

## Introspection

All three opcodes require a POST_TX call subtree and activate with Hegota
(`bogotaTime` in a shared genesis).

| Opcode | Byte | Operands, top first |
|---|---|---|
| TXTRACE | `0xb7` | index, selector |
| TXDIFF | `0xb8` | key/index, address/topic, selector |
| EVENTDATACOPY | `0xb9` | event index, memory offset, data offset, length |

`0xb5` is SIGDATACOPY; `0xb6` remains unassigned. TXTRACE exposes sorted balance,
storage, and deployment changes, ordered events, precharge, and payer. TXDIFF
supports before/after slot, balance, and codehash lookups; per-address storage
and event indices; account change flags; and topic count/index selectors
`0x0b`/`0x0c`. Topic views use all 256 bits, exclude the signature topic at index
0, and count an event once even if the topic repeats.

Before values are transaction-scoped, including when an account or slot is
already cached from an earlier transaction. State lookups pay the fork's
warm/cold access cost and record successful reads in the block access list.
Transaction-local views cost 100 and do not warm accounts or storage.
EVENTDATACOPY rejects out-of-range event indices and data ranges, including
zero-length copies with an invalid data offset.

## Local compatibility profile

See [the Reth devnet runner](../scripts/reth-devnet/README.md) for the pinned
runtime, genesis settings, build instructions, and executable two-client checks.
FOCIL can be scheduled independently with `focilTime`; omission preserves the
existing Hegota activation behavior.

Tests live in `test/tests/levm/eip7906_tests.rs` and the opcode module's unit
tests. They cover read-only enforcement, rollback, custom payment prefixes,
state gas, prestate cache paths, views, topic matching, and invalid operands.
